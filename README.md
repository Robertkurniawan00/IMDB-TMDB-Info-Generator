IMDB TMDB Info Generator

An HTML & JavaScript (Client-side) based project to automatically fetch movie data from TMDB using an IMDb ID. 
This program will instantly generate a ready-to-use HTML template for movie blog or forum posts, complete with a poster, synopsis, and cast list.

# Features
* Runs 100% directly in the browser.
* Uses the official TMDB API to fetch data safely and quickly based on the IMDb ID.
* Automatically fetches and arranges the top 5 main actors along with their profile pictures.
* Adds a movie trailer automatically just by entering a YouTube ID.
* The generated output uses inline styles, ensuring the layout remains intact when copied and pasted into Blogger, WordPress, or discussion forums.

# How to Use
1. Open the index.html` file in your browser.
2. Get a [TMDB API Key](https://www.themoviedb.org/settings/api) for free.
3. Enter your TMDB API Key, IMDb ID (example: `tt11971598`), and YouTube ID (example: `dQw4w9WgXcQ`).
4. Click **Generate**.
5. Copy the HTML code that appears in the bottom box and paste it into the HTML editor mode of your blog or website.

# Based on
* HTML5 & CSS3
* Vanilla JavaScript 
* The Movie Database (TMDB) API
